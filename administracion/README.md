# Panel administrativo

Aplicación Angular independiente para el Avance 4 de Tienda en Línea.

## Ejecutar

1. Levantar primero el servicio NestJS de la raíz del repositorio en `http://localhost:3000`.
2. En esta carpeta:

```bash
npm install
npm start
```

El panel abre en `http://localhost:4200`.

La dirección del servicio se cambia en `src/app/api/config.ts`.
